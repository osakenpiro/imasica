# IMASICA

**想像を立体で書く。** ブロック建築の設計図を3Dで回して見て、必要素材を数えて、人に渡すための単一HTMLツール。

→ **https://osakenpiro.github.io/imasica/**

依存なし・インストールなし・サーバーなし。HTMLファイル1つで完結し、オフラインでも動く。
データは端末の外に出ない。共有リンクは設計図そのものをURLに畳んだもの。

## できること

**見る** — 回して見る／層でスライスして骨組みを覗く／下から積み直して手順を見る／
ブロックをクリックして種類を特定する

**数える** — 必要素材を自動集計／3層ブロック（うえ・なか・した）を柱の連なりから正確に分配／
開口率と平面サイズのチェック／段ごとの断面図（実際に積むとき見るやつ）

**入れる** — ラフ画から立てる（レイヤー＝段／押し出し／濃淡＝高さ）／
JSONを貼る／AIに描かせるプロンプトを作る

**出す** — JSON／共有リンク（設計図ごとURLに入る）／PNG設計図カード／Blender用Python

## IMASICA形式

世界を離散で書くための最小フォーマット。**構造とパレットを分けて持つ**のが要点で、
パレットを差し替えるだけで、同じ形が別の素材・別のゲーム・別の世界のものになる。

```json
{
  "format": "imasica/v0",
  "meta": { "title": "小屋", "scale_m": 1 },
  "size": [5, 4, 4],
  "palette": { "W": { "name": "壁", "color": "#ddccaa", "role": "壁" } },
  "voxels": {
    "type": "layers",
    "layers": [
      ["WWWWW", "W...W", "W...W", "WWWWW"],
      ["WWWWW", "W...W", "W...W", "WWWWW"]
    ]
  }
}
```

`layers[y]` が下から y 段目の水平断面。行＝奥行き、文字＝幅、1文字1ブロック、`.` が空気。
人が読めて、AIが書けて、パーサが1行で座標に落とせる——その3つが同じ1枚を共有できることを狙っている。

`scale_m` は1セルが現実の何メートルか。ここを決めることは、その世界をどれくらいの粗さで書くかを決めること。

## 形の入口は3つ

| | 入口 | 性質 |
|---|---|---|
| **E Ross** | 絵から立てる | 情熱のまま描いた形をそのまま通す。速い、正確でない |
| **Logos** | 設計図を読む／書く | 同じ1枚から誰の手元でも同じものが立つ。堅い |
| **Wonder** | AIに描かせる | 手の外から来る。制御できない、遠くまで行く |

3つとも同じ形式に落ちるので、相をまたいで混ぜられる。

## 開発

`src/index.html` が編集用（three.js をCDN参照）。`src/build.py` が three.js を焼き込んで
配布用の単一HTMLを吐く。cdnjs の three.js は UMD ビルドが 0.160.0 までなので、それより上げない。
